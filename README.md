# Simple Interest Calculator

A simple script to calculate simple interest based on the principal amount, annual rate of interest, and time period in years.

## Formula
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal amount
- **R** = Annual interest rate (in percentage)
- **T** = Time period (in years)

## Usage
1. Input the principal amount ($P$).
2. Input the annual rate of interest ($R$).
3. Input the period in years ($T$).
4. Calculate the simple interest using the formula.

## Example
- **Principal (P):** 1000
- **Rate (R):** 5%
- **Time (T):** 2 years
- **Simple Interest:** $(1000 \times 5 \times 2) / 100 = 100$
